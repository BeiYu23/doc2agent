# order.uploadextrapackage

> 订单额外运单信息上传接口，适用于商品件数小于运单数量场景或者补发场景。商家通过发货接口上传运单号后，ISV通过接入该接口将多余的运单号回传到抖店系统，并展示给买家。

| 元信息 | 值 |
| --- | --- |
| 接口 ID | `doudian.logistics.order.uploadextrapackage` |
| 平台 | `doudian` |
| 请求方法 | `GET` |
| 接口路径 | `/order/uploadextrapackage` |
| Base URL | `https://openapi-fxg.jinritemai.com` |
| 鉴权方式 | `access_token+sign` |
| 文档来源 | https://op.jinritemai.com/docs/api-docs/16/4182 |
| 更新日期 | `2023-07-11` |

## 接口说明

- 文档书: 物流发货API（版本 V1.06）
- 公共参数（method/app_key/access_token/param_YOUR_SECRET_KEY_method）见 doudian/agent/_common.json

## 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `shop_order_id` | body | string | 是 | 店铺单号 | `6919571420622558781` |
| `product_orders` | body | array | 是 | 运单号关联的商品信息列表 | `` |
| `  └ bundle_product_list` | body | array | 否 | 组合商品信息列表 | `` |
| `    └ count` | body | number | 否 | 关联的组合商品的件数 | `1` |
| `    └ sku_id` | body | string | 否 | 组合商品中子商品的SkuID | `1235` |
| `    └ product_id` | body | string | 否 | 组合商品中子商品的商品ID | `1235` |
| `  └ product_count` | body | number | 否 | 选填。如果是组合商品，该字段为空，即使传递也不会被采用；如果是非组合商品，该字段必填，为大于0的整数。 | `1` |
| `  └ product_order_id` | body | string | 是 | 商品单单号 | `6919571420622558781` |
