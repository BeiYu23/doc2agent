# product.editSchema

> 商品发布schema编辑接口

| 元信息 | 值 |
| --- | --- |
| 接口 ID | `doudian.product.product.editSchema` |
| 中文名 | 商品发布schema编辑 |
| 平台 | `doudian` |
| 请求方法 | `GET` |
| 接口路径 | `/product/editSchema` |
| Base URL | `https://openapi-fxg.jinritemai.com` |
| 鉴权方式 | `access_token+sign` |
| 文档来源 | https://op.jinritemai.com/docs/api-docs/14/6371 |
| 更新日期 | `2026-07-15` |

## 接口说明

- 文档书: 商品API（版本 V2.01）
- 公共参数（method/app_key/access_token/param_YOUR_SECRET_KEY_method）见 doudian/agent/_common.json

## 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- | --- |
| `product_id` | body | mixed | 是 | 商品ID | `123` |
| `commit` | body | boolean | 是 | 是否提审 true提审、false保存草稿 | `true` |
| `token` | body | string | 是 | 商品发布token | `1234` |
| `model` | body | string | 是 | schema数据 | `""` |
| `recommend_ids` | body | string | 否 | 预测记录id，类目预测记录key=category_recommend_id | `{"category_recommend_id":"qwrqrw12341"}` |

## 请求示例

```bash
curl -X GET 'https://openapi-fxg.jinritemai.com/product/editSchema?app_key=your_appkey_here&method=product.editSchema&access_token=your_accesstoken_here&param_json={}&timestamp=2018-06-19%2016:06:59&v=2&sign=your_sign_here'
```
